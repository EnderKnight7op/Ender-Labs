# Privacy Policy

**Effective date:** October 4, 2026  
**Last updated:** October 4, 2026

This Privacy Policy explains how **Ender Labs** ("we", "us", or "our") handles information processed by our Discord applications, including **Garnet**.

By using a service operated by Ender Labs, you acknowledge this Privacy Policy. If you do not agree with it, please do not use the applicable service.

## 1. Scope

This policy applies to information processed by Ender Labs through our Discord applications and related services.

Discord is a third-party platform. Your use of Discord is also subject to Discord's own Terms of Service and Privacy Policy.

## 2. Information We Process

Depending on the features you use, Garnet may process limited Discord information needed to provide its functionality.

This can include:

- Discord user IDs
- Discord server (guild) IDs
- Usernames, display names, avatars, and other basic Discord profile information exposed to the bot
- Server roles and permissions needed to perform bot actions
- Information provided through commands, buttons, menus, and other interactions
- Configuration required for server features
- Ticket information created through the ticket system

Garnet does **not** intentionally request or collect Discord passwords, authentication tokens, payment card information, or similar credentials.

## 3. How We Use Information

Information is processed only as needed to:

- Provide and operate Garnet's features
- Respond to commands and interactions
- Manage server configuration
- Create and manage support tickets
- Store configuration and ticket data required for those features
- Maintain, troubleshoot, and secure the service
- Comply with applicable legal obligations

We do not sell Discord user data or use it for advertising.

We do not use Discord API data to build user profiles unrelated to Garnet's functionality.

## 4. Stored Data

Garnet may store server configuration and ticket-related information in its database.

The exact information stored depends on which Garnet features a server uses. Data that is no longer necessary for the relevant feature should not be retained longer than necessary.

## 5. Data Sharing

We do not sell, rent, or provide Discord user data to data brokers or advertising networks.

Information may be processed by service providers used to operate the service where necessary, or disclosed when required by law.

Discord itself processes information according to its own policies and terms.

## 6. Data Deletion and Requests

If you want data associated with Garnet removed, you can contact us through the [Ender Labs Discord server](https://dsc.gg/enderlabs).

For server configuration or ticket data, a server administrator may also be able to remove the relevant data through Garnet's available functionality.

We may need enough information to identify the relevant server or data before fulfilling a request.

We will handle valid deletion requests in accordance with applicable law and Discord's developer requirements.

## 7. Security

We take reasonable technical and organisational measures to protect information handled by our services.

However, no internet-connected system can be guaranteed to be completely secure. See our [Security Policy](https://github.com/EnderKnight7op/Ender-Labs/blob/main/SECURITY.md) for information about reporting security vulnerabilities.

## 8. Children's Privacy

Garnet is a Discord application and is not intended to knowingly collect personal information from children in violation of applicable law.

We do not intentionally request sensitive personal information from users.

## 9. Changes to This Policy

We may update this Privacy Policy when Garnet's functionality, data practices, or legal requirements change.

The "Last updated" date at the top of this page indicates when the policy was most recently revised.

## 10. Contact

For privacy questions or data requests, contact us through the [Ender Labs Discord server](https://dsc.gg/enderlabs).
